# DSH prompt 01 · Reference boards and equal blockout

Read the master prompt, audit intake, visual/camera briefs and all place cards. Open sourced photographs and the project reference images using the available viewing tools. Build a short evidence table per place with the source, one visible feature it supports, and what you are simplifying. Keep shoreline references as art inputs. Match prominent features only where current evidence supports them.

1. Set a local metre scene and shared camera convention per coast. Save independent working files with consistent object and collection IDs. Build coast silhouette, broad neighborhoods or terrain, water plane, jetty or bank, and the distinct survey anchors. Build topology beyond the frame far enough for an orbit and approach move. Inspect each at overhead, north-up and lateral angles. Do not begin detailed hero modeling with companion scenes still empty.
2. Block out the section and align it to the same survey anchor. Test two viewpoints against fixed world coordinates. Make the seabed clearly illustrative in the review sheet. Keep enough water area for future overlays and place the most readable landmark on the shore-water boundary.
3. Seed a geographic Blender sphere using the optional `references/globe/make_globe_seed.py` and its README, or assemble the sphere from the supplied globe texture, verify north and east and the three approximate site anchors, and set an Earth overview plus two regional framing tests. Check longitude and sign using the usage doc. At local scale, cut via composition rather than attempting a continent-to-boat continuous coordinate system.
4. Render a section and overhead clay proof for **all three** coasts. Create `work/reviews/blockout-parity.png` with labels and shared sizes. Put north-up or lateral proofs in work renders. At 320 px, name the distinct shape, shore anchor and boat for each coast. If one reads as a duplicate or hard-edged cropped tile, fix the blockout and re-render it now.
5. Save phase checkpoints, camera/anchor notes and next action, then proceed to 02.
