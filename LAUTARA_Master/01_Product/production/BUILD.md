Run python rebuild_portable.py in this folder with ReportLab, Pillow, PyMuPDF, the system Open Sans and Liberation fonts at the paths in the script, and the bundled flow.pdf. It writes layout.pdf and rebuilt_team_brief.pdf here. The 7 pages matched the pixels of the supplied final brief at 72 dpi in the packaging environment. Original render_casebrief.py preserves the earlier absolute output path; use the portable version for routine work. To edit the vector diagram, see flow.tex and compile with a LaTeX installation with TikZ. The compiled original flow.pdf is included.
